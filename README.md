# pi-x-ide — moved

This repository is archived. The Pi-side extension `@saifymatteo/pi-x-ide` now lives in
[saifymatteo/pi-extensions](https://github.com/saifymatteo/pi-extensions/tree/main/packages/pi-x-ide),
and releases from 1.22.0 onward publish from there. The npm package name is unchanged:

```bash
pi install npm:@saifymatteo/pi-x-ide
```

The editor plugins (VS Code, JetBrains, Neovim) were never changed in this fork; install them from upstream.

File issues at [saifymatteo/pi-extensions](https://github.com/saifymatteo/pi-extensions/issues).
Versions 1.21.0 and earlier, published from this repository, are Apache-2.0. From 1.22.0, saifymatteo's
changes are AGPL-3.0-only; the upstream Apache-2.0 license still covers the upstream code.

Upstream: [balaenis/pi-x-ide](https://github.com/balaenis/pi-x-ide).
